# Owner test: verified explanations for new questions

The October 22 owner requested a different way to reduce new-question delay and corrections for the factual errors found in the previous experiment. The selected approach answers a bounded set of general educational questions from reviewed local reference material. It keeps the existing Pro/Sol-low route for unmatched questions. It introduces no new model, provider, paid service, API key or voice setting.

**This improves covered questions; it does not make arbitrary new questions fast.** Fourteen defined question types cover sky color, sunlight color, raindrop shape, rain’s earthy smell, smell before rainfall, falling rain, rainbows, sound in a vacuum, music-memory associations, sunset color, Moon phases, seasons, day/night, and thunder. The matcher recognizes explicit whole-question forms and polite variants. A mixed request, private/current fact, clinical question, unsupported wording or care action continues through the existing authorized route.

The [OpenAI latency guidance](https://developers.openai.com/api/docs/guides/latency-optimization) recommends evaluating when a model request can be avoided. Here, the reference answer is already reviewed and stored locally. No model rewrites it before delivery. Heart still synthesizes the actual complete answer at its selected normal speed, using the same pinned checkpoint and existing 72-character test speech parts. There is no filler or early release of tentative model text.

The clean matched comparison used eight covered questions twice per path, reversing path order on the second repetition. All 32 answers used the actual conversation service, fresh owner/test-client authority, synthetic read-only facts and native Heart. Builds and regression tests did not overlap this final timing run. Median first validated audio was **4.796 seconds for the existing route and 0.9485 seconds for the reference route**. The 16 reference answers made zero model calls. All outliers remain in the evidence; these are small controlled samples, not production percentiles.

A separate final-source check used different question forms across all 14 answer types, validated every returned base-answer WAV part, and prepared the reviewed continuation audio without a model request. No model-generated answer cache was used to make a new question appear fast. Timing is measured from typed request to validated audio availability; microphone capture, transcription, browser transport and audible/physical-device listening are outside that measurement.

The factual corrections preserve distinctions that earlier model answers lost:

- Blue light scatters more than red; violet scatters even more. Ordinary sunlight combines visible colors and usually looks white. The source packet uses [NASA’s detailed light explanation](https://science.nasa.gov/ems/03_behaviors/) for the color comparison and [NASA’s sky/sunlight guide](https://spaceplace.nasa.gov/blue-sky/en/) for white sunlight and sunsets.
- Scents from nearby rainfall may be carried by wind before rain reaches a place. This is a possible explanation, not a determination of present weather or proof that approaching drops alone cause the smell. The [MIT rainfall study](https://news.mit.edu/2015/rainfall-can-release-aerosols-0114) supports release and dispersal of airborne soil compounds; applying that mechanism to a before-rain smell is explicitly qualified.

The earlier incomplete compound answer about sunlight was retained as an unsuccessful precision check. The packet now includes a positive white-sunlight fact and a dedicated sunlight-color answer. Four revised compound questions through Pro preserved the white/blue/violet distinctions, uncertainty about approaching rain, and the difference between rotation and tilt. Compound/unmatched educational questions receive relevant bounded source facts and trusted guidance to preserve qualifications, while retaining the original model-completion and authority checks. This improves the tested factual grounding; it does not guarantee arbitrary model accuracy or eliminate their generation delay.

The other reviewed material comes from [NASA’s raindrop description](https://gpm.nasa.gov/science/anatomy-of-a-raindrop), [falling-object explanation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/free-falling-objects/), [sound-in-space explanation](https://science.gsfc.nasa.gov/attic/cosmicopia.gsfc.nasa.gov/qa_sp_ev.html), [Moon phases](https://science.nasa.gov/moon/moon-phases/), [seasons and rotation](https://spaceplace.nasa.gov/seasons/en/), the [author-hosted music-memory study](https://pscresearch.faculty.ucdavis.edu/wp-content/uploads/sites/112/2014/11/Janata-music-evoked-memories.pdf), and the [National Weather Service’s thunder explanation](https://www.weather.gov/safety/lightning-science-overview). The music study is small and concerns young adults; the answer does not promise a treatment effect or improved personal memory.
